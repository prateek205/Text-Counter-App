# 📝 Text Counter App (Vanilla JavaScript)

A simple and interactive **Text Counter Application** built using **HTML, CSS, and Vanilla JavaScript**.  
This app allows users to analyze text in real-time while supporting **Dark / Light Mode** for better accessibility and user experience.

## 🚀 Features

- 🔢 Real-time character count  
- 🧾 Word count functionality  
- ⏱️ Instant text analysis as you type  
- 🌗 Dark / Light mode toggle  
- 💾 Theme preference persistence (optional)  
- ⚡ Lightweight and fast  
- 📱 Fully responsive design  

## 🛠️ Tech Stack

- **HTML5** – Structure  
- **CSS3** – Styling & themes  
- **JavaScript (Vanilla JS)** – Logic & DOM manipulation

## ⚙️ How It Works

- User enters text in the input area
- JavaScript tracks characters and words in real-time
- Dark / Light mode toggles using class switching
- UI updates instantly without page reload
- Optional: Theme state can be saved in `localStorage`
